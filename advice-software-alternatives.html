03 / USE A SHARED REQUIREMENTS LIST

Compare the same work and period.

  1. Write down the critical scenarios

    Include normal work, exceptions, permissions, reports and specialist tools. Separate essential capabilities from preferences.

  2. Request evidence

    Use authorised sample data. Record demonstrated capabilities, configuration requirements, gaps and unanswered questions.

  3. Agree delivery and continuity

    Document migration, acceptance criteria, training, support, updates and exit arrangements.

Compare the full commitment.

Include implementation, migration, licences, usage, retained tools, training and support. Customer data, tenancy control, application licences and ownership of custom work are different matters. Check each proposal and contract.
